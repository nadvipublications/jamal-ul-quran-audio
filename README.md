# Jamal ul Quran - Audio downloads

This repository contains downloadable audio data for the Jamal ul Quran mobile application by Nadvi Publications.

Audio is distributed through Releases. The app downloads only the selected Surah, verifies its size and SHA-256 hash, and saves it for offline playback.

Version audio-v1 provides normal-speed Arabic recitation for all Surahs, with the approved Arabic/Balochi Al-Nas preview including Bismillah. Filenames contain content hashes and must not be overwritten with different audio.

Audio and text rights remain with their respective rights holders. This repository contains no application source code, signing keys or credentials.
